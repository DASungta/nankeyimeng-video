## 这次怎么做

分工一句话：我写剧本、分镜和提示词，在 Muse 的旁聊里请它出图、出视频，逐帧审片后剪辑、配乐；你看成片、提意见。全片 41 个镜头（含 13.5 秒片头）、约 223 秒，中英双语字幕。梦外用写实古装电影质感，梦里用唐代工笔重彩；片头现用写实版（冷开场、中英双语职员表、书法片名卡），绢画版备用。

流程分四步：

1. 先出 7 张设定图，把人物和画风定下来（已完成；人物的样子见下文“人物定型”）。
2. 逐镜先出关键帧，选定后再生成视频。Muse 的视频越往后越容易走样，多数镜头只用前半段；提示词里写死“摄影机固定在三脚架上完全不动”，要动的东西和不许变的东西都写明。
3. 四组对照镜头（A～D）要成对生成：先出梦里那一镜，再拿它当构图参考出梦外那一镜。
4. 每看完一版成片，按制片人意见改提示词、重出关键帧或视频、调整剪辑和配乐；每一轮的问题和做法记在 `docs/muse-review.md`。

画面里一律不出现文字。Muse 写汉字不可靠，所以匾额上的「大槐安国」「南柯郡城」、人物名章、字幕和片名都由我在后期加。

## 故事与改编

全片靠一个反转立住：梦里二十年的荣华，醒来只是槐树下的一窝蚂蚁，杯里的酒还没有干。故事取自唐代李公佐的传奇《南柯太守传》，情节和关键台词都照原文，只删去他与父亲通信、契玄法师等支线（原文见[维基文库](https://zh.wikisource.org/wiki/南柯太守傳)）。

这部片子是给不知道这个典故的人看的（制片人，2026-10-16），所以：旁白一律用白话；要紧的东西开头就先交代，院里的老槐、树根下的洞、进出的蚂蚁、两位酒友的名字（名章）；两次穿越各用一个看得清的镜头，入梦是车子穿过院子钻进那棵树的洞（S06），出梦是破车驶向发亮的洞口（S17）；梦里梦外的人物一律定型，前后对得上；情节转折的地方（公主病逝到国王起疑）镜头放长、叠化放慢，旁白把因果说清。

**梗概**

1. 唐朝贞元年间，扬州（广陵）。淳于棼家的院子里有一棵老槐树，树根底下有个洞，蚂蚁成群进出。
2. 他原是军官，酒后顶撞上司丢了官，常和酒友周弁、田子华在树下喝酒。这天他又喝醉了，朋友把他扶到东廊下睡下。
3. 梦里两个紫衣使者来请：「槐安国王遣小臣致命奉邀。」他坐上青油小车，车子朝院中的老槐树驶去，钻进了树根下的洞里。
4. 洞里是大槐安国。国王召见他，把金枝公主嫁给他；婚宴上他遇见周弁、田子华；陪国王在灵龟山打猎；出任南柯太守二十年，百姓为他立碑建祠，五个儿子做官、两个女儿嫁入王族。
5. 邻国檀萝发兵来犯，周弁在瑶台城大败；不久公主病逝。他辞去太守，护送灵柩回京，国王和满朝权贵出城迎候；公主葬在盘龙冈。
6. 他守郡多年，权贵早与他交好，回京后宾客盈门，国王起了疑心。有人上书说天象示警、国有大难、都城将要迁徙，祸根是个外族人；众人都说应在他身上。国王撤去他的侍卫，把他软禁在家，最后说「卿本人间，家非在此」，用一辆破车送他回去。
7. 他在东廊下醒来：朋友还在院里洗脚说笑，「斜日未隐于西垣，余樽尚湛于东牖」。梦里二十年，人间才一个下午。
8. 他带朋友扒开树洞，果然是蚁穴：丹色土台上两只「素翼朱首」的大蚁就是国王和王后；南枝上的小土城是南柯郡；盘曲如龙的老根旁一尺高的小土堆是公主的坟；宅东古涧边的老檀树下还有一窝，就是檀萝国。
9. 当夜风雨大作，第二天蚁群全部不见，应了「都邑迁徙」的谶语。他从此戒了酒，再不求功名。后来人们用「南柯一梦」比喻一场空欢喜的大梦。

**梦里的蚁迹**。梦中每个场景都藏一点蚂蚁的影子，第一遍看不出来，反转之后回想都对得上：

- 天空是层层叠叠的巨大槐叶，金绿色的光从叶缝里漏下来。
- 宫城用红褐色夯土筑成，像蚁穴的泥土；建筑本身照唐代形制画，不加奇幻的孔洞。
- 紫衣使者和朝臣的幞头脚细长上翘，暗合蚂蚁的触角。写实镜头里只做到一尺长，提示词里也不能写“触角”，否则 Muse 会画成真触角。
- 国王白衣、朱红冠，跪坐在朱红台座的御床上，对应原文的「其色若丹」「素翼朱首」。
- 公主的披帛薄如蝉翼，半透明。
- 檀萝国的兵穿深褐配藤绿的甲，盔上缠着藤蔓。

**全片结构**（原文档这里是一张结构图，导出时没带上）：第一段 古槐与醉卧（S00A～S06，写实）→ 第二段 梦中二十年（S07～S17，工笔）→ 第三段 醒来揭穿（S20～S28，写实与微距）。对照镜头：A 余樽与斜日 S04 / S20，B 丹台上的国王与蚁王 S09 / S22，C 盘龙冈与小土堆 S14 / S24，D 藤萝爬城与檀萝之国 S12 / S26A。

A 组是同一机位重拍，看的是时间几乎没走；B、C 两组是同一构图换画风，看的是梦里的宫殿和山冈原来是蚁穴和树根。

看过串联预览后加了第四组对照 D：梦里 S12 藤萝爬满瑶台城，醒后 S26A 宅东老檀树被藤萝缠满，树下也有蚁穴——「檀萝之国，岂非此耶」。

### 梦里：唐代工笔重彩

像一幅会动的唐代绢画，石青、石绿、朱砂、泥金。室外镜头的天空一律是金绿色的巨大槐叶，这一句已写在各镜头里，没有放进后缀。

关键帧后缀（S07～S17）：

```
唐代工笔重彩绢本设色画风，细劲流畅的铁线描勾勒轮廓，石青、石绿、朱砂、赭石与泥金矿物颜料，平涂与分染，绢的细密经纬纹理，微微泛黄的古旧感，人物修长端庄，参考唐代宫廷人物画与敦煌壁画的富丽，构图疏密有致，有留白，16:9，画面中不要出现文字、印章和落款。
```

```
保持工笔绢画的平面质感、线描和矿物色，不要变成三维写实；人物动作轻缓克制，镜头只做缓慢的平移或推近。
```

### 画风怎么切换

- 片头：现用写实版，两个写实镜头叠着片头字幕，转黑出书法片名，S00A 从黑里亮起。备用的绢画版（S00→S00A）：古槐先是一幅绢上的画，墨色从树洞晕开把它画出来；镜头推进画里的树洞，推到和 S00A 第一帧里的真树洞对齐，画叠化成真实的古槐。观众先看到“画”，再看到“真”，梦里的工笔世界在这里先露一面。
- 入梦（S06→S07）：青油小车跟着两个紫衣使者穿过院子，钻进古槐树根下的洞，画面落入全黑。约半秒后，墨色从黑暗中晕开，绢纹浮现，工笔世界像画卷一样展开。
- 出梦（S17→S20）：破车驶向洞口的亮光，最后 0.8 秒压到全白，从白里直接切到写实的酒樽和斜日（S20），再回到廊下熟睡的他（S18），他猛然睁眼（S18A）。
- 紫衣使者是唯一在两个世界之间来回的梦中人：S05、S06 里他们以写实的样子出现，引他入梦；S18 他们已经隐去，只剩画外的呼名声。

## 唐代史实规范

梦里的大槐安国可以奇幻，但城、宫、屋、器物都要按唐代来画。蚂蚁的暗示只藏在不违背史实的地方：天上的槐叶、丹色和夯土的颜色、成列的大臣。建筑上不开蜂窝孔，画面里不出现真龙和真触角。

| 对象 | 按唐代应该是 | 不要 |
| --- | --- | --- |
| 都城 | 方正的长方形。宫城、皇城在北面正中，一条宽阔的南北中轴大街直通宫城（长安朱雀大街记载“广百步”，约 150 米），街巷横平竖直，把城分成一百多个方正的里坊（《唐六典》） | 圆形或环形城墙 |
| 城墙与城门 | 夯土城墙，看得出一层层版筑夯层。城门是夯土墩台上的木构城楼，都城正门可一门五道（明德门） | 墙上开孔、砖砌拱券门洞 |
| 宫殿 | 高夯土台基，朱红柱、白墙，斗拱硕大，屋坡平缓、出檐深远，正脊两端用鸱尾，灰黑筒瓦，最多绿琉璃剪边；殿内是成排的粗大红柱，方砖铺地。可参照五台山佛光寺东大殿（857 年） | 明清式高翘檐角、龙吻、满铺黄琉璃；拿露天帷帐当宫殿 |
| 坐具与坐姿 | 唐代跪坐、盘腿坐、垂足坐并行。椅子最迟唐代已出现，但初期多在室外用，正式场合尊者“座于床”。国王跪坐在御床上，身前凭几，身后屏风 | 高背椅、宝座椅 |
| 民居 | 悬山或歇山顶，屋坡平缓、出檐深远，直棂窗，原木色立柱配白墙 | 江南明清式马头墙、高翘檐角 |
| 山水 | 青绿山水：墨线勾山石轮廓，石青石绿重彩，山头尖而层叠，山势逶迤。可参考李思训《江帆楼阁图》、敦煌莫高窟第 217 窟壁画 | 把“盘龙冈”画成山上卧着一条龙 |
| 衣冠 | 中唐幞头：巾子圆而不高，两脚软垂，或略硬、微微上翘 | 高筒硬帽、长脚朝天 |

写提示词时只写看得见的形状，不写比喻：“像一对触角”“像一条龙”都会被 Muse 照字面画出来。

出处：坐具与坐姿见[扬之水《家具史发展史中若干细节的考证》](https://www.aisixiang.com/data/89266.html)；朱雀大街宽度和明德门五门道见[光明网报道的西安五桥遗址考古](https://m.gmw.cn/baijia/2023-01/13/1303253709.html)；里坊数见《唐六典》“皇城之南，东西十坊，南北九坊……凡一百一十坊”。

**我这边怎么合成**。`` 是一个 Remotion 工程，沿用《清明上河图》的做法：`edl.json` 管每镜用哪条视频、入点和时长，`tools/prep_clips.py` 由它生成 `src/clips.json`；`src/Film.jsx` 画两处画风转场、名章、眼皮开合、闪电和片名，`src/subs.js` 是字幕，`music/make-music.mjs` 生成配乐。成片 1920×1080、24 帧。Muse 的视频镜头一动就每 24 帧跳一帧，用 `tools/dejudder.py` 按光流补帧；视频里有硬切的地方不能补，否则会生出鬼帧，只用硬切之前的部分。梦里有运镜的九个镜头（S07、S08、S10C、S12B、S12、S13、S14、S15、S17）再用 tools/smooth\_motion.py 处理：Muse 的运镜每 8 帧一轮、忽快忽慢，工笔的细墨线又没有运动模糊，24 帧下看着像帧率很低（制片人意见，2026-10-17）；这一步把步子拉匀，并加上相当于 180° 快门的拖影，帧数和时长不变；最后一镜 S27 也按同样办法拉匀（写实画面本身带拖影，不再加模糊）。
